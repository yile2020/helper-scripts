# 研修助手 · 脚本猫（ScriptCat）发布说明

> 目的：给打不开 GitHub / raw.githubusercontent.com 的大陆用户一个国内安装入口。
> GitHub 仍然是完整说明、源码和反馈的主入口；脚本猫只做「国内备用安装」。

## 一、已查到的和没查到的

| 项目 | 结论 | 来源 |
|---|---|---|
| 安装链接格式 | `https://scriptcat.org/scripts/code/{编号}/{脚本名}.user.js` | 脚本猫上的现有脚本页 |
| 不写 `@updateURL` 时 | 默认用安装链接把 `user.js` 换成 `meta.js` 来检查更新 | 脚本猫开发文档「脚本元数据」 |
| 发布规范 | 禁止恶意代码、混淆加密、以脚本为载体发广告；描述要「准确反映功能、权限及可能的影响」；有付费、返佣、追踪等要用 `@antifeature` 声明 | 脚本猫《服务协议》第三节 |
| 自动同步 | 市场里有标着「该版本为系统自动同步更新」的版本，说明支持某种同步，**怎么配置没查到** | 脚本猫脚本版本页 |
| 会不会改写脚本自带的 `@updateURL` | **没查到** | — |
| 发布前审核 | **有审核**。首页横幅（2026-11-21）：「近期发现以引流、广告为目的的脚本开始泛滥，将进行整治和处理，此类脚本将不再通过审核」 | 脚本猫首页 |
| 是否要手机号或实名 | **没查到** | — |
| 网课、学习平台类脚本 | 规范里没有专门条款；站内搜「暑期教师研修」能搜到多个同类脚本（有的标榜「秒刷」「一键完成全部学时」，其中有广告位），所以教程让读者用**直达链接**，不要站内搜 | 脚本猫搜索页 |

这里的关键是**从脚本猫装的人，以后从哪里检查更新**。如果还是从 GitHub 检查，大陆用户装上了也更新不了。所以本目录提供了一份**去掉 `@updateURL` / `@downloadURL` 的副本**，见下面第二节。

## 二、发布步骤

### 1. 生成要粘贴的代码

```bash
node promo/src/scriptcat-build.cjs
```

生成的 `promo/scriptcat/smartedu-2026-basic.user.js` 和仓库版只差两行：去掉了指向 GitHub 的 `@updateURL` 和 `@downloadURL`。去掉之后，Tampermonkey 会从安装来源（脚本猫）检查更新。

`@name` 和 `@namespace` 没改，Tampermonkey 会把 GitHub 版和脚本猫版认成同一个脚本。装过 GitHub 版的人再从脚本猫装一次，只会覆盖成脚本猫的更新来源，不会出现两份。

### 2. `@author` 里的微信号：保留（2026-11-21 决定）

脚本猫版和 GitHub 版一样，`@author` 保留 `壹樂（V：ita1125）`。

注意：脚本猫首页写明「以引流、广告为目的」的脚本不再通过审核，作者栏的微信号有可能被当成引流。

如果脚本猫审核或后台提示违反「禁止以脚本为载体发布广告」，再改成只写 `壹樂`：在 `src/scriptcat-build.cjs` 里加一步替换就行，GitHub 版不受影响。

### 3. 在脚本猫上发布

1. 打开 `scriptcat.org` 注册并登录。
2. 找到发布 / 上传脚本的入口。**发布表单的具体字段我没查到，以实际页面为准。**
3. 代码：粘贴第 1 步生成的文件全文。
4. 如果表单提供「从网址同步」：**先别用 GitHub 的 raw 地址同步。** 同步过来的代码会带着指向 GitHub 的 `@updateURL`，大陆用户还是更新不了。除非你在第三节第 3 步确认了脚本猫会把更新地址改成它自己的。
5. 名称、简介、详细描述：用第四节的文案。

### 4. 以后每次发新版

1. 先更新 GitHub 版（`@version` 必须比上一版高）。
2. 运行 `node promo/src/scriptcat-build.cjs` 重新生成副本。
3. 在脚本猫的脚本页更新代码，粘贴新副本。

## 四、脚本猫页面文案

**名称**：用脚本自带的 `@name`，不用改：
`2026年暑期教师研修|国家中小学智慧教育平台|自动连播助手`

**简介（一句话）**：

> 国家中小学智慧教育平台 2026 暑期教师研修（基础教育）：自动展开章节、播完接下一个、可选学完自动进下一门，后台标签页继续播放。个人维护的免费开源脚本，非平台官方。

**详细描述**（Markdown）：

```markdown
## 这是什么

适用于 [国家中小学智慧教育平台](https://basic.smartedu.cn/) 2026 年「暑期教师研修」专题（基础教育）的 Tampermonkey 脚本。个人维护、免费开源（MIT），**不是平台官方工具**。

本页是**国内备用安装入口**。完整说明、源码、问题反馈在 GitHub：https://github.com/yile2020/helper-scripts

## 能做什么

- 从平台接口读出专题里的全部课程，面板列出课程名、学时上限和学习进度
- 点一门课开始：自动展开章节，跳过已学完的，播完接下一个；打开「自动续学」后学完一门自动进入下一门
- 倍速播放，默认 2 倍速，面板里可以改
- 切到别的标签页、最小化窗口，视频也不会停
- 每看完 5 个视频、连续出错或播放卡住 3 分钟，会自动刷新页面接着学
- 遇到问题点「诊断」，报告复制到剪贴板

## 请先了解

- **课堂练习会自动作答并提交**：没有题库，单选选第一个、多选选前两个，不保证正确。介意的话请自己作答。
- **同一账号只在一个地方学**：平台检测到多处同时学习会暂停，请关掉手机 App 和其他浏览器里的学习页。
- **学时以平台记录为准**，不承诺任何学时、证书或结果，请隔段时间在平台上核对，并遵守平台学习要求。
- **权限**：只用 GM_setValue / GM_getValue / GM_deleteValue 在本机保存设置和进度；网络请求只发往平台自己的接口，没有统计或上报。
- **脚本免费**，看到有人收费出售请不要购买。

## 怎么安装

1. 电脑上用 Edge 或 Chrome 安装「篡改猴」（Tampermonkey），国内建议用 Edge 扩展商店
2. 在浏览器的扩展管理页，给篡改猴打开「允许用户脚本」（旧版浏览器是「开发者模式」）
3. 点本页的安装按钮，在篡改猴弹出的页面点「安装」
4. 登录平台，打开 2026 暑期教师研修专题，右侧出现「研修助手」面板就装好了
```

> 「课堂练习会自动作答」放在最前面，是因为脚本猫规范要求描述「准确反映功能、权限及可能的影响」。这一条在小红书教程里没提，在脚本猫页面上要写明。
