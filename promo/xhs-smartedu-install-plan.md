## 三、GitHub README 新手入口优化建议

现状问题（对照当前 README）：

1. 研修助手小节排在「贵州省网络研修专题自动续课」**后面**，从小红书来的人要先滚过「快速开始」和贵州专题才能看到。
2. 研修助手小节的「怎么用」第 1 步是「按快速开始装好……」，新用户要在页面里上下跳。
3. 「快速开始」第 2 步把 Edge 和 Chrome 写在一起（「详细信息」「开发者模式」是两家混用的叫法），而且 `edge://extensions` / `chrome://extensions` 这类地址在 GitHub 里不能点，需要提示复制。
4. 不少读者会在手机上点开链接，README 没说「手机装不了，请用电脑」。
5. 「点了安装却看到一堆代码」是零基础用户最常见的问题，常见问题里没有。
6. 首页标语「自动刷课连播」里的「刷课」和教程的措辞边界不一致，建议改成「自动连播」。
