## 正文

置顶那篇好多老师问「求脚本」「怎么操作」，统一写一篇。有两种安装方式，国内打不开 GitHub 也能装👇

📌 先说清楚
· 研修助手是我个人维护的免费开源脚本，不是国家中小学智慧教育平台的官方工具
· 学时和证书以平台记录为准，我不承诺任何结果
· 脚本免费，看到有人卖的不要买

💻 你需要准备
· 一台电脑（Windows / Mac 都行），手机和平板装不了
· Edge 或 Chrome 浏览器，国内建议用 Edge（Windows 自带，扩展商店能正常打开）
· 能正常登录研修平台的账号

🧩 所有人先做（图 3–6）
① 装浏览器扩展「篡改猴」（Tampermonkey）：Edge 扩展商店搜「篡改猴」，认准开发者 Jan Biniok
② 打开「允许用户脚本」。这一步最容易漏，Edge 和 Chrome 的位置不一样，分开讲了

📥 再选一种方式装脚本（装一个就行）
🅰 GitHub（图 7）：打开 github.com/yile2020/helper-scripts，往下找到「2026 暑期教师研修自动连播助手」，点「👉 点击安装」
🅱 脚本猫 · 国内备用（图 8）：GitHub 打不开的，直接打开 scriptcat.org/zh-CN/script-show-page/9185 点安装。别在脚本猫站内搜，同类脚本很多，容易装错

✅ 然后都一样（图 9–10）
③ 篡改猴弹出安装页，核对脚本名后点「安装」
④ 登录 basic.smartedu.cn，打开 2026 暑期教师研修专题，右侧出现「研修助手」面板就装好了

🛠 装不上先看图 11：
· GitHub 或「点击安装」打不开 → 用方式 B
· 点安装后满屏代码 → 篡改猴没装好，或「允许用户脚本」没开
· 看不到面板 → 开关没开，或者没刷新页面
· 视频自己停了 → 同一账号在手机 App 或别的浏览器也开着，关掉只留一个

🔗 最新版、完整说明和反馈都在 GitHub，搜 yile2020/helper-scripts。两种方式装的都会自动更新。

还是不行就在评论说卡在第几张图，或点面板「诊断」把报告发到仓库 Issues。

请遵守平台的学习要求，使用后果自行承担。
